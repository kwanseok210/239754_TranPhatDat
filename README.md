
# Hệ thống quản lý nhân sự

## 1. Thông tin sinh viên
- Họ và tên: Tran Phat Dat
- MSSV: 239754
- Lớp: DH23TIN10

## 2. Mô tả hệ thống
Xây dựng hệ thống quản lý nhân sự với giao diện web React,
backend Node.js/Express và cơ sở dữ liệu MongoDB Atlas.

Các chức năng chính:
- Xem danh sách nhân viên
- Xem chi tiết nhân viên
- Thêm nhân viên
- Tìm kiếm theo mã hoặc họ tên
- Cập nhật thông tin nhân viên
- Xóa nhân viên

## 3. Công nghệ sử dụng
- Frontend: React
- Backend: Node.js, Express
- Database: MongoDB Atlas
- Version control: Git, GitHub
- Container: Docker, Docker Hub
- Deployment: Render

## 4. Cấu trúc dự án
- backend/: API và xử lý dữ liệu
- frontend/: giao diện người dùng

## 5. Hướng dẫn chạy dự án
Sẽ cập nhật sau khi hoàn thành phần backend và frontend.
